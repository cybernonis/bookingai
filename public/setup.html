Ειδοποιήσεις κρατήσεων

Ρύθμισε email και SMS — τόσο για εσένα (admin) όσο και για τους πελάτες.

📧 Email
Επέλεξε πάροχο αποστολής email. Αν δεν θες email, επέλεξε "Χωρίς email".
Pre-filled από το Βήμα 1. Εδώ θα στέλνονται οι ειδοποιήσεις νέας κράτησης.
Οδηγίες Gmail App Password
  1. Πήγαινε στο myaccount.google.com → Ασφάλεια
  2. Ενεργοποίησε 2-Step Verification (αν δεν είναι ήδη)
  3. Πήγαινε myaccount.google.com/apppasswords → Mail → Επέλεξε συσκευή
  4. Αντέγραψε τον 16-ψήφιο κωδικό που εμφανίζεται
Οδηγίες Resend
  1. Εγγραφή στο resend.com (δωρεάν)
  2. Από το dashboard: API Keys → Create Key
  3. Αντέγραψε το API key
  4. Για email αποστολέα: χρησιμοποίησε onboarding@resend.dev (δοκιμαστικό) ή δικό σου domain
⚠️ Στο δωρεάν πλάνο χωρίς domain: μόνο αποστολή στο δικό σου email. Για πελάτες χρειάζεσαι δικό domain.
Οδηγίες SendGrid
  1. Εγγραφή στο sendgrid.com (δωρεάν)
  2. Settings → Sender Authentication → Single Sender Verification → επιβεβαίωσε email
  3. Settings → API Keys → Create API Key → Mail Send → Full Access
  4. Αντέγραψε το API key (ξεκινά με SG.)
Στέλνει δοκιμαστικό στο email του Βήματος 1.
📱 SMS
Επέλεξε πάροχο αποστολής SMS. Αν δεν θες SMS, επέλεξε "Χωρίς SMS".
Pre-filled από το Βήμα 1. Εδώ θα στέλνονται τα SMS νέας κράτησης.
Οδηγίες Brevo SMS
  1. Εγγραφή στο brevo.com (δωρεάν — 300 SMS/μήνα)
  2. Από το menu: Transactional → API Keys → Create a new API key
  3. Αντέγραψε το API key
⚠️ Αν χρησιμοποιείς Railway, το Brevo μπορεί να απαιτεί whitelist IP. Αν λάβεις σφάλμα αδείας, δοκίμασε Twilio.
Οδηγίες Twilio
  1. Εγγραφή στο twilio.com
  2. Dashboard → Account SID + Auth Token (αρχική σελίδα)
  3. Phone Numbers → Buy a number (ή χρήση δωρεάν trial αριθμού)
  4. Αντέγραψε τον αριθμό σε μορφή +1xxxxxxxxxx
Στέλνει δοκιμαστικό στο τηλέφωνο του Βήματος 1.
✅ Επιβεβαίωση πελάτη (αυτόματο)
Μετά από κάθε κράτηση ο πελάτης λαμβάνει αυτόματα:
📧 Email επιβεβαίωσης — αριθμός κράτησης, διαδρομή, τιμή (χρησιμοποιεί τον πάροχο που επέλεξες)
📱 SMS επιβεβαίωσης — σύντομη επιβεβαίωση με αριθμό κράτησης
