Ειδοποιήσεις κρατήσεων

Ρύθμισε πώς θα ενημερώνεσαι για κάθε νέα κράτηση.

📧 Email ειδοποιήσεων
Λαμβάνεις email για κάθε νέα κράτηση. Χρησιμοποιεί SendGrid (δωρεάν 100 emails/ημέρα).
Pre-filled από το Step 1 — μπορείς να χρησιμοποιήσεις διαφορετικό.
Οδηγίες SendGrid (απαιτείται για αποστολή email)
  1. Εγγραφή στο sendgrid.com (δωρεάν)
  2. Settings → Sender Authentication → Single Sender Verification → προσθήκη email
  3. Settings → API Keys → Create API Key (Full Access)
  4. Στο Railway: SENDGRID_API_KEY=SG.xxx και SENDGRID_FROM=your@email.com
⚠️ Χωρίς SendGrid τα emails δεν θα αποστέλλονται. Το SMS και η κράτηση λειτουργούν κανονικά.
📱 SMS ειδοποιήσεων
Λαμβάνεις SMS για κάθε νέα κράτηση. Χρησιμοποιεί Vonage (~€0.06 ανά SMS).
Pre-filled από το Step 1 — μπορείς να χρησιμοποιήσεις διαφορετικό.
Οδηγίες Vonage (απαιτείται για αποστολή SMS)
  1. Εγγραφή στο vonage.com (δωρεάν, €2 credit)
  2. Από το dashboard: API Key (8 χαρακτήρες) + API Secret
  3. Στο Railway: VONAGE_API_KEY=xxx, VONAGE_API_SECRET=xxx, VONAGE_FROM=BooklyAi
⚠️ Χωρίς Vonage τα SMS δεν θα αποστέλλονται. Η κράτηση λειτουργεί κανονικά.
✅ Επιβεβαίωση πελάτη (αυτόματο)
Μετά από κάθε κράτηση αποστέλλονται αυτόματα:
📧 Email επιβεβαίωσης στον πελάτη (SendGrid) — εμφανίζει αριθμό κράτησης, διαδρομή, τιμή
📱 SMS επιβεβαίωσης στον πελάτη (Vonage) — σύντομη επιβεβαίωση με αριθμό κράτησης
